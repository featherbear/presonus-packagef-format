# PreSonus PACKAGEF (`.skin`) File Format

PreSonus' Universal Control has a bunch of `.skin` files which contains resources.  
These `.skin` files are of a `PACKAGEF` format, whose structure is reverse-engineered and documented here

* [Markdown](./presonus_packagef.md)
* [Kaitai Struct](./presonus_packagef.ksy)

---

The `viewer/` directory contains a web application that implements the data structure.  
It is available at https://featherbear.cc/presonus-packagef-format/
